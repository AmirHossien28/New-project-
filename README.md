# پیدانو (Pidano)

پلتفرمی برای **کشف کسب‌وکارها**، **دنبال‌کردن آدم‌ها و کسب‌وکارها** و **انتشار محتوا**.

این مخزن در حال حاضر **مرحله اول (پایه طراحی و صفحه خانه)** را در بر دارد: دو زبان فارسی/انگلیسی،
چیدمان RTL/LTR، تم روشن و تاریک، هدر و ناوبری، و صفحه خانه با داده نمونه.

> ⚠️ داده‌های فعلی **نمونه** هستند. هنوز هیچ دیتابیس، احراز هویت یا آپلود فایلی وجود ندارد.

## ۳. اجرا روی ویندوز (PowerShell)

```powershell
# ۱) اگر مخزن را تازه Clone کرده‌اید:
cd E:\pidano

# ۲) نصب بسته‌ها (فقط بار اول، یا وقتی package.json تغییر کرد)
npm install

# ۳) اجرای محیط توسعه
npm run dev
```

سپس در مرورگر باز کنید: <http://localhost:3000>

سایر دستورها:

```powershell
npm run build     # ساخت نسخه production (باید بدون خطا و بدون هشدار تمام شود)
npm run start     # اجرای نسخه ساخته‌شده
npm run lint      # بررسی کیفیت و قواعد کد
npm run typecheck # ساخت نوع‌های مسیرها و بررسی TypeScript
```

> نکته مهم: مسیرهای پروژه در `src/app/[locale]` هستند و Next.js نوع‌های `PageProps` / `LayoutProps` را
> خودش هنگام build یا dev تولید می‌کند. اگر پوشه `.next` را پاک کنید و مستقیم `npx tsc --noEmit` بزنید،
> خطای «Cannot find name 'PageProps'» می‌گیرید — این یعنی نوع‌ها هنوز ساخته نشده‌اند، نه اینکه کد خراب است.
> به همین دلیل همیشه از `npm run typecheck` استفاده کنید که اول `next typegen` را اجرا می‌کند.

```

│  │  ├─ login/            ← صفحه موقت
│  │  └─ business/[slug]/  ← صفحه موقت
│  ├─ globals.css          ← توکن‌های طراحی، فونت‌ها، استایل پایه
│  └─ icon.svg             ← آیکون برند
├─ components/
│  ├─ brand/               ← لوگو
│  ├─ layout/              ← هدر، پاورقی، منوی موبایل، سوییچ زبان
│  └─ ui/                  ← دکمه، کارت، آواتار، نشان وضعیت، نوار جست‌وجو، …
├─ features/               ← کد مخصوص هر قابلیت
│  ├─ business/            ← کارت کسب‌وکار
│  ├─ post/                ← کارت پست
│  ├─ category/            ← کارت و آیکون دسته‌بندی
│  └─ home/data/           ← داده نمونه
├─ config/site.ts          ← زبان‌ها، مسیرها، نام برند
├─ i18n/                   ← دیکشنری‌های fa.json و en.json
├─ lib/                    ← ابزارهای مشترک (cn، اعداد، پالت رنگ)
├─ types/                  ← نوع‌های مشترک
└─ proxy.ts                ← هدایت آدرس بدون زبان به /fa یا /en
```

## ۵. تصمیم‌های فنی این مرحله (و دلیلشان)

**۱. زبان در آدرس، نه در state**
مسیرها `/fa/...` و `/en/...` هستند. دلیل: زبان فقط ترجمه متن نیست؛ جهت چیدمان، فونت و لینک‌های
قابل اشتراک‌گذاری هم تغییر می‌کنند. فایل `src/proxy.ts` آدرس بدون زبان را بر اساس کوکی کاربر،
سپس `Accept-Language` مرورگر و در نهایت زبان پیش‌فرض (`fa`) هدایت می‌کند.

**۲. فونت‌ها self-host شده‌اند**
فایل‌های `woff2` در `public/fonts` قرار دارند و در `globals.css` با `@font-face` و `unicode-range`
معرفی شده‌اند. دلیل: بدون درخواست به سرورهای گوگل، سریع‌تر، سازگار با حریم خصوصی (GDPR) و مستقل از دسترسی به اینترنت.
`unicode-range` باعث می‌شود مرورگر فقط بخش موردنیاز فونت (عربی/لاتین) را دانلود کند.

**۳. توکن‌های طراحی به‌صورت متغیر CSS**
رنگ‌ها در `:root` و `.dark` تعریف و سپس با `@theme inline` به کلاس‌های Tailwind وصل شده‌اند
(`bg-surface`، `text-muted-foreground`، `bg-primary` …). نتیجه: تغییر تم بدون تکرار کلاس‌ها انجام می‌شود.

**۴. `cacheComponents` خاموش است**
در Next.js 16 این گزینه (که پیش‌فرض روشن است) استفاده از `usePathname` را بیرون از `<Suspense>` ممنوع می‌کند؛
ما برای مشخص‌کردن «صفحه فعال در منو» به آن نیاز داریم. در فاز «عملکرد» می‌توان با طراحی آگاهانه Suspense روشنش کرد.

**۵. داده نمونه از کامپوننت جدا است**
داده‌ها در `src/features/home/data/home-data.ts` و شکلشان در `src/types` است. در فاز دیتابیس، فقط
همین لایه با کوئری‌های Prisma عوض می‌شود و کامپوننت‌ها دست‌نخورده می‌مانند.

## ۶. چطور تست کنیم

| موضوع | کار | نتیجه مورد انتظار |
|---|---|---|
| صفحه خانه | باز کردن `/` | هدایت خودکار به `/fa` یا `/en` بر اساس زبان مرورگر |
| دو زبان | کلیک روی دکمه زبان (آیکون کره) | آدرس و متن‌ها عوض می‌شوند؛ در `/fa` چیدمان راست‌به‌چپ و فونت وزیرمتن |
| تم تاریک | کلیک روی آیکون ماه/خورشید | کل صفحه تیره می‌شود؛ بعد از Refresh انتخاب حفظ می‌شود |
| واکنش‌گرایی | باریک‌کردن پنجره تا عرض موبایل | منوی همبرگری ظاهر می‌شود؛ کارت‌ها یک‌ستونی می‌شوند |
| دنبال‌کردن | کلیک روی «دنبال کردن» | برچسب به «دنبال می‌کنید» عوض می‌شود (فقط ظاهری، بدون سرور) |
| جست‌وجو | تایپ و Enter | رفتن به `/fa/search?q=...` (صفحه فعلاً موقت است) |
| دسترس‌پذیری | Tab زدن در صفحه | ترتیب فوکوس مشخص و حلقه فوکوس قابل‌دیدن است |

## ۷. مرحله بعد

پیشنهاد: **صفحه جست‌وجو و کشف** (`/search`) با فیلتر دسته‌بندی و شهر، سپس **صفحه کسب‌وکار** و
**پروفایل کاربر**. بعد از آن، احراز هویت و در نهایت اتصال دیتابیس.

هیچ بخشی از این پروژه نباید بدون توضیح و تأیید مالک پروژه تغییر کند.
